Detecting the gates in a hand-drawn circuit is only half the problem; the connections between them also have to be recovered. This project compared YOLO, Faster R-CNN, RetinaNet and Detectron2 for gate detection, and developed a boundary-tracking method to interpret the wiring.

Published in *IEEE Access* — see [Publications](/publications/).

**Stack:** Python · YOLO · Detectron2 · OpenCV
